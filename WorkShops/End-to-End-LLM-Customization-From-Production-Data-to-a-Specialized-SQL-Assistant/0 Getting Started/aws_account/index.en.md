# Access your AWS Account

## At an AWS Event

1. Navigate to the Workshop Studio URL provided by your instructor.

2. Select **Email one-time password (OTP)** to sign in.

![Workshop Studio sign-in page with the Email one-time password (OTP) option highlighted above Login with Amazon and Amazon employee options](../../images/otp.png)

3. Enter your email address and click **Send passcode**.

![One-time email passcode screen with an email address entered in the Email field and the Send passcode button highlighted](../../images/enter-email.png)

4. Check your inbox for the one-time passcode.

![Email titled Your one-time passcode from no-reply@us-east-1.otp.signin.aws.training, with the passcode highlighted below the text Your one-time passcode is](../../images/otp-email.png)

5. Enter the passcode and click **Sign in**.

![One-time email passcode verification screen with the 9-digit passcode field and the Sign in button highlighted](../../images/otp-enter.png)

6. If prompted, enter the 12-digit **Event access code** provided by your instructor, then click **Next**.

![Workshop Studio Join event page, Step 1 Enter event access code, with the access code field and the Next button highlighted](../../images/access-code.png)

7. Accept the terms and conditions, then click **Join event**.

![Workshop Studio terms and conditions page with the Join event button](../../images/terms.png)

8. You will land on the Workshop Studio page. Click **Open AWS Console** on the left side panel.

![Workshop Studio event dashboard with the AWS account access section expanded in the left panel and the Open AWS console link highlighted](../../images/ws_landing.png)

9. The AWS Console opens in a new tab. Check the **Region** selector in the top-right corner and confirm it matches your event's region — for most events this is **US East (N. Virginia)** (`us-east-1`), as shown below. If it shows a different region, switch to your event's region before proceeding: every later lab looks for resources created in that one region, so working in the wrong region will make them fail.

![AWS Management Console home page opened in a new browser tab, showing the Region selector set to US East (N. Virginia) in the top-right corner](../../images/aws_console.png)
